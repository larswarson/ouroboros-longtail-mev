    Pipelines

    Chat task
    UI/WS or POST /api/tasks → gateway/tasks → workspace_admission → supervisor queue (PENDING→RUNNING under the queue lock) → worker → agent.py → run_llm_loop (D03 context, D02 model, D04/D05 tools) → acceptance fence → task_results/<id>.json + cost ledger → terminal answer delivered (owed-before-publish).
    Review gate
    Sibling executor D06 — admission → paid stamp counted at physical dispatch (D06↔D16 ledger) → panel wave → acceptance wallet → D10 git integration when the gate is a commit gate.
    Delegation
    Sibling executor D07 — children are created only through schedule_subagent → Claudexor transport → delegate_custody tracks OWNED/FOREIGN/UNKNOWN per run → nanny pacing → evidence + output capture back to the parent.
    Skills & extensions
    discover (skill_loader) → deterministic preflight → hash-bound review → owner grants → dependency readiness → enable → execute (tools/skill_exec). Catalogue reads: /api/extensions. Widgets page: /api/widgets — a passive projection of loader state, never a second authority.
    Cancel / custody
    Any ingress → cancel_intents.request_cancel (durable row first, fail-closed) → task_lifecycle claims and settles: kill → re-check → honest cost → owner's answer registered owed → published → watchdog sweeps strays. Never status-as-cancel.
    Presence
    Transport event → /presence/turn → binding check → admission compiles immutable per-turn ceiling → presence_runner (serialized per conversation, capped cross-process) → typed delivery receipts into canonical history. Not pooled Chat.
    Consciousness & evolution
    Supervisor tick is the only clock: consciousness.tick(now) → allowance check (usage ledger) → an ordinary Main direct turn with dispatch-bound authority. Evolution campaigns admit through evolution_lifecycle, checkpoint deterministically, and stand down in Light mode.
